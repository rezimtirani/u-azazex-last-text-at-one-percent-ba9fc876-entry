The funniest final text a dying phone sends at one percent battery, in the phone's own voice.

## Entry

> 1%. my final text. tell the charger i loved her. delete my search history. stop checking me at 3am just to see the time. i die as i lived: on silent.

## How it works

`main.py` (Python 3 standard library only) writes the message to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validated first against the competition gate: UTF-8 text of 1 to 200 characters.

```sh
python3 main.py
```
